# bout-de-code-fr-fr

## Requirements

- [Retraceur](https://retraceur.github.io/) >= 1.0.0
- [Bout de code](https://github.com/imath/bout-de-code) >= 1.2.0

## Description

French translation for the [Bout de code](https://github.com/imath/bout-de-code) Retraceur block.

## Installation

Copy all files having their names starting by the `bout-de-code-fr_FR` term and paste them into the `/wp-content/languages/plugins/` directory of your personal [Retraceur](https://retraceur.github.io/) Website.
